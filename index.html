Dica rápida

Coloque o sistema na tela inicial

Assim ele abre como um aplicativo, sem precisar procurar o navegador. Se preferir, feche esta dica e continue usando pelo navegador normalmente.

iPhone

No iPhone (Safari)

  1. Abra este sistema no Safari.
  2. Toque em Compartilhar (quadrado com seta para cima).
  3. Escolha Adicionar à Tela de Início.
Android

No Samsung / Android (Chrome)

  1. Abra este sistema no Chrome.
  2. Toque no menu de três pontos (⋮).
  3. Escolha Adicionar à tela inicial.
